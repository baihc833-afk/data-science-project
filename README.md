# Customer Churn Analysis Project

## 1. The problem or research question
- **Research Question**: What are the primary factors driving customer churn in the telecommunications sector, and can we accurately predict which customers are likely to leave?

## 2. Dataset source and usage permissions
- **Source**: Telco Customer Churn dataset (Publicly available via Kaggle).
- **Permissions**: Open-source dataset permitted for educational and analytical use.

## 3. Methods and tools used
- **Tools**: Python, Pandas, Scikit-Learn, Matplotlib, Seaborn.
- **Methods**: Exploratory Data Analysis (EDA), Data Preprocessing, Feature Engineering, and Logistic Regression / Random Forest Modeling.

## 4. Key findings and one limitation
- **Key Findings**: Customers with month-to-month contracts and high monthly charges have a significantly higher churn rate. Fiber optic internet users also showed unexpected high churn due to higher support ticket issues.
- **Limitation**: The dataset lacks qualitative customer feedback (e.g., customer service call transcripts), which could provide deeper context into churn reasons.
